Developer & Hospital Integration

RESTful Inference API Documentation

Integrate cardiovascular diagnostic machine learning inference directly into Electronic Health Record (EHR) systems, hospital software, or mobile applications.

GET /api/health
System Liveness & Model Status

Returns server uptime, operational status, and active production model name. 

curl -X GET http://127.0.0.1:5000/api/health
Sample Response (200 OK):
{
  "model_loaded": "Random Forest",
  "service": "CardioSense Heart Disease Prediction API",
  "status": "healthy",
  "version": "1.0.0"
}
POST /api/predict
Single Patient Risk Scoring

Takes a JSON payload containing 11 clinical biomarkers and returns probability percentage, risk tier, diagnostic summary, and individual contributing factors. 

curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "Age": 58,
    "Sex": "M",
    "ChestPainType": "ASY",
    "RestingBP": 140,
    "Cholesterol": 240,
    "FastingBS": 1,
    "RestingECG": "ST",
    "MaxHR": 130,
    "ExerciseAngina": "Y",
    "Oldpeak": 2.0,
    "ST_Slope": "Flat"
  }'
Sample Response (200 OK):
{
  "success": true,
  "data": {
    "prediction": 1,
    "prediction_label": "Heart Disease Detected",
    "probability_percent": 96.8,
    "probability_healthy_percent": 3.2,
    "risk_tier": "HIGH",
    "badge_color": "danger",
    "clinical_summary": "High probability of coronary heart disease detected by diagnostic indicators.",
    "action_plan": "Immediate cardiologist consultation, diagnostic echocardiogram or coronary angiography strongly advised.",
    "risk_factors": [
      "Flat ST Slope during peak exercise (common sign of myocardial ischemia)",
      "Exercise-induced angina present (chest pain during physical exertion)",
      "Asymptomatic chest pain type (historically high correlation with silent CAD)",
      "Elevated ST depression Oldpeak (2.0 mm) indicates significant ischemic response",
      "Fasting blood sugar > 120 mg/dl (hyperglycemia increases cardiovascular risk)"
    ],
    "protective_factors": [],
    "model_name": "Random Forest"
  }
}
POST /api/batch-predict
Multi-Patient Cohort Assessment

Accepts a multipart CSV upload or JSON list of patients to process hundreds of records synchronously. 

# Via CSV file upload:
curl -X POST http://127.0.0.1:5000/api/batch-predict \
  -F "file=@patients_cohort.csv"
GET /api/models
Benchmark Comparison Metrics

Returns full benchmarking data, confusion matrices, and optimal hyperparameters across all evaluated ML algorithms. 

curl -X GET http://127.0.0.1:5000/api/models
